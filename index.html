Algorithm Documentation

1. Breadth First Search (BFS)

Principle: Uses a FIFO Queue to explore layer by layer.

Advantages: Complete & Optimal.

Limitations: Exponential memory consumption.

Time: O(b^d) | Space: O(b^d)

2. Depth First Search (DFS)

Principle: Uses a LIFO Stack to explore down branches fully before backtracking.

Advantages: Very memory efficient.

Limitations: Not optimal, can get stuck in infinite paths without loop detection.

Time: O(b^m) | Space: O(bm)

3. Iterative Deepening (IDDLS)

Principle: Runs DFS with an increasing depth limit.

Advantages: Optimal and complete, but memory efficient like DFS.

Limitations: Re-evaluates upper tree layers multiple times.

Time: O(b^d) | Space: O(bd)

4. A* Search

Principle: Informed search using a Priority Queue and evaluation function f(n) = g(n) + h(n).

Advantages: Highly efficient, complete, and optimal (with admissible heuristic).

Limitations: Retains all generated nodes in memory.

Time: Varies by heuristic | Space: O(b^d)
